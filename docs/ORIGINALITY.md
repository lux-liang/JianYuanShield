## 1. LIDMark — 人脸关键点结构感知水印

### 1.1 核心设计与数学动机

LIDMark 的出发点是：现有隐式水印（HiDDeN / SepMark）的嵌入目标是"最小化全图感知失真"，并不区分人脸语义结构；一旦面部经过 Deepfake 换脸处理，非语义位置的水印残差可能随面部纹理一起被替换掉。LIDMark 转而把 152 维水印向量分为两段：前 136 维编码 dlib 面部关键点坐标（连续浮点，作为结构锚），后 16 维编码用户 ID（二进制 `{-1, +1}`）。编码器（LIDMarkEncoder）和全息解码器（FHD，Full Holographic Decoder）以 128×128 人脸对齐输入联合训练，损失设计为加权重建损失 + 消息 BCE + 关键点位置正则项，使网络在保持面部几何结构的同时将 ID 信息写入关键点邻域的高频细节层。数学上，这相当于把水印信号的"关注中心"约束到由面部拓扑定义的空间子集，而非随机散布全图——使得 Deepfake 换脸后只要保留面部关键点区域（大多数面部替换算法会保留眼/鼻/口的位置结构），ID 水印就有可能幸存。

### 1.2 与公开方法的本质差异

**对比 HiDDeN（Zhu et al., ECCV 2018）**：HiDDeN 以卷积编码器 + 噪声层（JPEG/裁剪/高斯噪声的可微代理）端到端训练，消息向量均匀分布到图像全局像素，解码器为对称卷积结构。LIDMark 在此框架外引入了"关键点驱动的结构感知嵌入"：编码器输入包含 136 维面部关键点坐标作为空间引导，解码器 FHD 输出分叉（关键点恢复头 + ID logits 头），训练目标包含关键点位置正则项。差异在于：HiDDeN 是无语义约束的盲嵌入；LIDMark 是面部语义驱动的结构嵌入，目标场景为 Deepfake 换脸攻击后的溯源。

**对比 SepMark（Wu et al., ACM MM 2023）**：SepMark 将图像分为高频（HF）和低频（LF）两条支路，分别训练各自的编码-解码分支并在 JPEG/噪声上做独立鲁棒性优化。LIDMark 不做频域分离，而是做"人脸关键点空间分离"：152 维向量的语义分区（坐标 vs. ID）决定了网络的训练目标权重，而非频率子带的选择。SepMark 的创新维度是频域；LIDMark 的创新维度是人脸语义结构域。

### 1.3 差异化对比表

| 维度 | HiDDeN (ECCV 2018) | SepMark (MM 2023) | **LIDMark（本团队）** |
|------|-------------------|-------------------|----------------------|
| 嵌入域 | 空域（全图均匀） | 频域（高频/低频分支） | 人脸关键点结构域（152-D 语义向量） |
| 消息编码 | 128-bit / 全局 | 128-bit / 双支路 | 16-bit ID + 136-D 坐标锚（`{-1,+1}`） |
| 解码器结构 | 对称卷积解码 | R-F 双解码器 | FHD 双头（关键点恢复头 + ID logits 头） |
| 抗攻击侧重 | JPEG / 裁剪（可微代理） | JPEG / 噪声（频域鲁棒） | Deepfake 面部替换后溯源（关键点区域保活） |
| 是否 landmark 感知 | 否 | 否 | **是**（dlib 关键点坐标引导嵌入位置） |
| 是否多嵌入红队测试 | 否 | 否（公开版本） | **是**（参与 MEA 4×4 矩阵评测） |
| 已知局限 | 弱几何鲁棒性 | 需训练双支路 | ID bit-acc 尚未完整测量（评测进行中） |

## 2. KAD-Net — 基于 Kolmogorov–Arnold 网络与 SE 注意力的水印模型

### 2.1 核心设计与数学动机

KAD-Net（Kolmogorov–Arnold Distillation Network）的出发点是：传统卷积水印编码器用固定激活函数（ReLU / GELU）的 MLP 层，把水印信号叠加到所有通道；但图像的不同频率通道对视觉感知和水印鲁棒性的贡献差异显著。KAD-Net 引入两项设计：①用 KAN（Kolmogorov–Arnold Network）替换编码器中的 MLP 全连接层，以可学习的单变量函数（B-spline 基）对消息向量做非线性映射，使网络拥有更高的参数利用率来拟合"消息→水印残差"的映射；②在 Encoder 和 Decoder_C 中嵌入 SE（Squeeze-and-Excitation）注意力模块，通过 channel-wise 全局平均池化 + 两层全连接门控，动态选择最优嵌入通道，降低对视觉敏感通道的干扰。训练采用蒸馏式课程：先在 clean 条件下稳定嵌入，再逐步引入 JPEG/噪声/几何增强（GEOM 微调阶段），使鲁棒性逐步提升而不丢失不可见性。

### 2.2 与公开方法的本质差异

**对比 HiDDeN（Zhu et al., ECCV 2018）**：HiDDeN Encoder 为标准 Conv-BN-ReLU 堆叠，无注意力机制，消息向量经 FC 层映射后以残差方式加到图像特征图（全通道均等处理）。KAD-Net 在此基础上：①用 KAN 层替换消息 FC 层，以 B-spline 可学习函数增强消息映射表达力；②用 SE 注意力对通道做软选择，使嵌入集中于视觉不敏感通道。结果：KAD-Net 在 JPEG/noise/resize 攻击下 bit-acc 均 ≥99.09%（EC_50，n=13,233），显著优于 HiDDeN 在 JPEG Q=50 下的 57.09%。

**对比 SepMark（Wu et al., ACM MM 2023）**：SepMark 通过频域分离（HF/LF 双支路）实现鲁棒性，是频域架构创新。KAD-Net 属于空域+注意力架构创新，核心不同在于：用可学习函数（KAN）+通道注意力（SE）替换 SepMark 的频域分离策略，在单支路架构下达到可与频域方法竞争的鲁棒性，且避免了 SepMark 双解码器带来的训练复杂性。

### 2.3 差异化对比表

| 维度 | HiDDeN (ECCV 2018) | SepMark (MM 2023) | **KAD-Net（本团队）** |
|------|-------------------|-------------------|----------------------|
| 嵌入域 | 空域（残差，全通道） | 频域（HF/LF 分支） | 空域（SE 通道注意力选择） |
| 消息映射 | 标准 FC + ReLU | 双支路 FC | **KAN（B-spline 可学习函数）** |
| 解码器 | 卷积对称解码 | Decoder_C + Decoder_RF 双解码 | Decoder_C（+ SE 注意力） |
| 抗攻击侧重 | JPEG / 裁剪（可微代理） | JPEG / 噪声 | JPEG / noise / resize（GEOM 微调）|
| 是否 landmark 感知 | 否 | 否 | 否 |
| 是否多嵌入红队测试 | 否 | 否（公开版本） | **是**（MEA 4×4 矩阵，几何攻击失败已如实标注） |
| 已知局限 | JPEG 鲁棒弱 | 训练复杂度高 | **几何攻击实质失败**（crop≈68.9%，rotate≈43.7%） |

- [ ] **KAN vs MLP 消融**：将 KAN 层替换回标准 FC+ReLU，控制参数量相近，对比 JPEG Q=50 bit-acc。
- [ ] **SE 注意力消融**：去掉 SE 模块（仅保留 KAN），观察 clean vs JPEG 攻击下 bit-acc 变化。
- [ ] **GEOM 微调消融**：使用 clean-only 训练的 checkpoint 与 GEOM 微调版（EC_50）对比几何攻击（crop/rotate）鲁棒性，确认 GEOM 微调带来的增量（即便当前仍失败，增量可量化）。
- [ ] **消息长度消融**：16-bit vs 30-bit vs 64-bit 对不可见性（PSNR/SSIM）与鲁棒性的 trade-off。
- [ ] **蒸馏课程消融**：去掉分阶段课程（直接同时加全部攻击），对比收敛速度与最终指标。

## 3. MEA — 多嵌入攻击评测协议

### 3.1 核心设计与数学动机

MEA（Multi-Embedding Attack Protocol）的动机是：现有水印评测均假设"图像只含一个水印"的单嵌入场景，而真实内容平台（图片分发、再创作）存在多方顺序嵌入的场景（创作者 A 先嵌入，转载方 B 再嵌入）。MEA 将这一现象形式化为三步协议：

1. **第一轮嵌入**：Source 模型 $M_A$ 在图像 $I_0$ 中嵌入消息 $w_A$，得到含水印图 $I_1$，记录 $acc_A^{(1)} = \text{bit\_acc}(M_A.\text{decode}(I_1), w_A)$。
2. **攻击嵌入**：Attacker 模型 $M_B$ 在 $I_1$ 中继续嵌入消息 $w_B$，得到 $I_2$。
3. **双路解码**：计算 `first_message_retention` = $\text{bit\_acc}(M_A.\text{decode}(I_2), w_A)$（先嵌水印残留率），以及 `second_message_acc` = $\text{bit\_acc}(M_B.\text{decode}(I_2), w_B)$（后嵌水印精度）。

通过构建 4×4（或更大）矩阵（行=Source，列=Attacker）可系统性评估任意两个水印模型之间的"共存兼容性"。MEA 最重要的发现是：大多数模型组合下 first_message_retention ≈0.5（随机），说明后嵌入几乎完全覆盖先嵌入的溯源信息——这是真实平台场景下的安全风险发现，而非协议失效。

### 3.2 与公开方法的本质差异

**对比 HiDDeN（Zhu et al., ECCV 2018）**：HiDDeN 提供了水印鲁棒性（JPEG/裁剪/噪声攻击）的单嵌入评测框架；MEA 在此之上新增了"竞争者嵌入"这一攻击维度，系统测量跨模型水印共存的兼容性。HiDDeN 及其后续工作（StegaStamp、Stable Signature 等）均未提供标准化的多方顺序嵌入兼容性矩阵评测协议。

**对比 SepMark（Wu et al., ACM MM 2023）**：SepMark 在单嵌入场景下测量了多种攻击的鲁棒性，但未涉及"第二个水印模型对第一个水印的干扰"评测。MEA 与 SepMark 的差异不在于模型架构，而在于评测协议维度的扩展：从"单嵌入+物理/压缩攻击"扩展到"多嵌入+跨模型语义攻击"。据调研，文献中对多水印顺序嵌入场景进行系统性协议化评测（标准化双路解码 + 可重复矩阵 + 兼容性分级）的工作较少覆盖。

### 3.3 差异化对比表

| 维度 | HiDDeN 评测范式 | SepMark 评测范式 | **MEA（本团队协议）** |
|------|----------------|-----------------|----------------------|
| 攻击场景 | 单嵌入 + 物理/压缩攻击 | 单嵌入 + 物理/压缩攻击 | **多嵌入 + 跨模型覆盖攻击** |
| 评测矩阵 | 攻击类型 × 指标 | 攻击类型 × 解码器 | **Source 模型 × Attacker 模型（兼容性矩阵）** |
| 双路解码 | 否 | 否 | **是**（先嵌残留率 + 后嵌精度分别报告） |
| 是否 landmark 感知 | 否 | 否 | 否（协议无约束，适用任意水印模型） |
| 是否多嵌入红队测试 | 否 | 否 | **是（本协议核心）** |
| 已知局限 | — | — | 当前 n=128/格（小样本），对角线 FAIL 部分可能受口径 bug 影响，待大样本重跑 |

### 3.4 消融实验清单（占位，待跑）

- [ ] **样本量消融**：n=128 vs n=1024/格，对比各格 first_message_retention 均值与 95%CI 宽度，确认小样本偏差量。
- [ ] **消息独立性消融**：$w_A$ 和 $w_B$ 使用相同随机消息 vs 正交消息，对比 first_message_retention 差异（检验消息相关性的干扰）。
- [ ] **嵌入顺序消融**：(A→B) vs (B→A) 的 first_message_retention 是否对称，揭示不同模型嵌入强度不同带来的非对称性。
- [ ] **阈值敏感性消融**：grade() 阈值从协议 0.9 降至 0.85/0.65，对比 PASS/MARGINAL/FAIL 格数变化，验证分级对阈值的敏感性。
- [ ] **攻击叠加消融**：MEA + JPEG Q=50 复合（先二次嵌入，再压缩），对比纯 MEA 下 first_message_retention，量化压缩对先嵌水印的额外破坏。

## 4. WaveGuard — 双树复小波水印

### 4.1 核心设计与数学动机

WaveGuard 的动机是：基于空域残差的水印（HiDDeN 类）在低质量 JPEG 压缩（Q≈50）下因量化噪声直接污染像素残差而失效；而纯频域方法（DCT 域水印）缺乏方向选择性，对旋转/裁剪等几何变换鲁棒性不足。WaveGuard 选择**DTCWT（双树复小波变换）**作为嵌入域：DTCWT 具备近似平移不变性、方向选择性（6 个实方向子带）和完美重建特性，兼具频域定位（JPEG 量化对应的频率子带可针对性选择）与一定几何容忍度。嵌入路径为：RGB→YUV→选取 U 通道高频子带（`indices_enc` 选择的特定频带）→卷积编码器将 30-bit 消息嵌入选定子带→IDTCWT 重建→YUV→RGB。解码路径使用二进制 detector（decoder_d）对选定子带直接输出 30-bit 检测结果，而非全图解码，降低了噪声干扰。团队在此基础上进行了 16 轮 JPEG 增强微调（model_state_16.pth），使非 Q=50 区间鲁棒性大幅提升至≈100%。

### 4.2 与公开方法的本质差异

**对比 HiDDeN（Zhu et al., ECCV 2018）**：HiDDeN 在 RGB 空域叠加水印残差，JPEG Q=50 量化直接损毁残差；WaveGuard 把消息嵌入 DTCWT 频域子带，高频量化影响被部分限制在特定子带，使 jpeg70/jpeg90/noise/resize 全部达到≈100%。关键区别：嵌入信号的物理载体从"像素残差"变为"小波子带系数增量"，解码路径也从"全图卷积解码"变为"子带选择检测"。

**对比 SepMark（Wu et al., ACM MM 2023）**：SepMark 的频域分离是在模型内部做 HF/LF 特征分支，仍以像素域端到端训练；WaveGuard 是在**显式 DTCWT 变换域**中操作，变换本身不可学习，编码器仅负责修改选定子带系数。差异在于：SepMark 是学习驱动的隐式频域分离，WaveGuard 是基于数学变换的显式频域嵌入（更可解释，嵌入位置物理意义明确）。

### 4.3 差异化对比表

| 维度 | HiDDeN (ECCV 2018) | SepMark (MM 2023) | **WaveGuard（本团队）** |
|------|-------------------|-------------------|------------------------|
| 嵌入域 | 空域像素残差（全图） | 隐式频域（学习 HF/LF 分支） | **显式 DTCWT 频域（U 通道高频子带）** |
| 变换类型 | 无 | 学习驱动特征频域 | **双树复小波（DTCWT，方向选择 + 近似平移不变）** |
| 解码器 | 对称卷积解码 | Decoder_C + Decoder_RF | **子带选择二进制 detector（decoder_d）** |
| 抗攻击侧重 | JPEG / 裁剪（可微代理） | JPEG / 噪声（频域鲁棒） | JPEG70+/noise/resize（DTCWT 频域保护），**jpeg50 仍为已知弱点** |
| 是否 landmark 感知 | 否 | 否 | 否 |
| 是否多嵌入红队测试 | 否 | 否（公开版本） | **是**（MEA 4×4 矩阵） |
| 已知局限 | JPEG Q≤60 失效 | 双支路训练复杂度 | **jpeg50 bit-acc≈89%/成功率仅 37%**，需进一步改进 |

- [ ] **U 通道 vs Y 通道消融**：将嵌入从 U 通道改到 Y 通道（亮度），对比不可见性（PSNR/SSIM）与 JPEG 鲁棒性 trade-off。
- [ ] **DTCWT vs DCT 消融**：在同等 QP 下对比 DTCWT 子带与 DCT 块系数作为嵌入载体的鲁棒性差异。
