# JianYuanShield：基于多模型协同的人脸深度伪造溯源系统

**信息安全作品赛参赛报告**

---

## 摘要

深度伪造（Deepfake）技术的迅速普及带来严峻的网络信息安全挑战。本作品设计并实现了 **JianYuanShield**——一个基于多模型协同水印的人脸深度伪造溯源平台。系统集成四个来自本团队的研究成果（SepMark、WaveGuard、LIDMark、KAD-Net），提出**多嵌入攻击（Multi-Embedding Attack，MEA）**协议作为评估水印鲁棒性的新基准，构建从水印嵌入、攻击仿真到溯源证据链的完整闭环。KAD-Net（EC_50，GEOM 微调，n=13,233）JPEG/noise/resize 全部 ≥99%，几何攻击（crop≈68.9%/rotate≈43.7%）为已知局限；WaveGuard（model_state_16，n=13,233）clean/jpeg70+/noise/resize≈100%，jpeg50 bit-acc≈89%/成功率仅 37%（真弱点）；SepMark（n=13,233）bit-acc≈85-89%（clean 87.74%）；HiDDeN（epoch-300，n=13,233）clean/resize 好，JPEG 域 gap 为已知局限，作有效对照 baseline；LIDMark（512×3 张）landmark 定位成功率 99.93%（ID 比特精度评测进行中）。

## 一、背景与意义

### 1.1 深度伪造威胁现状

据 Deeptrace 2023 年报告，全球 Deepfake 视频数量在 2022–2023 年间增长超过 300%，92.5% 以上针对真实人脸，广泛用于舆情操纵、身份欺诈和隐私侵犯。现有内容平台（微信、抖音、小红书）尚无成熟的主动溯源机制，仅能被动检测，无法追溯内容来源创作者。

### 1.2 现有方案的不足

| 方案类型 | 代表工作 | 局限 |
|---------|---------|------|
| 被动检测 | FaceForensics++, XceptionNet | 无来源信息，无法归因 |
| 单一水印 | HiDDeN, RivaGAN | 单模型脆弱性，平台转码后失效 |
| 人脸特定方案 | FaceGuard | 缺乏对 ID 信息的精确编码 |
| 区块链存证 | NFT 溯源 | 链上确认慢，无法嵌入媒体本身 |

### 1.3 本作品的核心定位

JianYuanShield 提出**多模型协同 + ID 精确编码 + MEA 鲁棒评估**的主动取证方案，据调研，多水印并存场景的系统性评测协议在文献中较少覆盖，专注于可实际部署的内容溯源闭环。

### 2.2 关键设计原则

- **适配器隔离**：每个模型通过独立 Adapter 类封装，避免 Python sys.path 命名空间冲突
- **统一攻击接口**：`_apply_attack_rgb()` 实现 15 种攻击的一致调用
- **证据链完整性**：水印嵌入时记录 Ed25519 签名，解码结果可追溯到创作者
- **模型热切换**：单请求可指定任意模型，系统自动完成初始化和推理

## 三、核心模型

### 3.1 SepMark（频域分离水印）

**技术原理**：将图像分离为高频和低频两个分支，水印信号嵌入高频子带，利用 R-F 联合解码器提升 robustness。

**本团队改进**：
- 训练 decoder_RF（Robustness-Focused 解码器），在噪声和压缩攻击下精度显著优于原始 decoder_C
- 在统一评测框架下对齐推理接口，支持实时 API 调用

**LFW 全量基准（n=13,233，checkpoint EC_115.pth）**：

| 攻击类型 | Decoder_RF | Decoder_C |
|---------|-----------|-----------|
| 无攻击 | **87.74%** | 87.74%（clean 约 88%；decoder_RF "91.2%" 为特定 decoder 偏高，以 ~88% 为基准）|
| JPEG Q=50 | 87.75% | — |
| JPEG Q=70 | 89.23% | 89.2% |
| 高斯噪声 | 87.19% | 87.2% |
| 缩放 | 84.65% | 84.7% |

> bit-acc≈85-89%（"decoder_RF 91.2%"偏高，以 ~88% 为准或注明特定 decoder）；success@0.9 为 59-72%（128-bit 长消息，门槛严）。

### 3.2 WaveGuard（双树复小波水印）

**技术原理**：利用 DTCWT（双树复小波变换）将水印嵌入频域高频子带，通过 binary 检测器判断水印存在性，具备方向选择性和平移不变性。

**本团队改进**：
- 16 轮 JPEG 增强微调（基于 fine_tuning.yaml）
- 修复 model_adapters.py 中的 sys.path 命名空间冲突（WaveGuard `network/` 与 KAD-Net `network/` 包名冲突）

**LFW 全量基准（n=13,233，checkpoint model_state_16.pth）**：

| 攻击类型 | bit-acc | success@0.9 |
|---------|---------|-------------|
| 无攻击 | **100%** | 100% |
| JPEG Q=70 | 99.68% | 99.64% |
| JPEG Q=90 | 100% | 100% |
| 高斯噪声 | 100% | 100% |
| 缩放 | 100% | 100% |
| **JPEG Q=50** | **88.97%** | **37.3%**（真弱点）|

> **jpeg50 是真弱点**：bit-acc≈89%，但 success@0.9 仅 37.3%——大量图像恰好低于 0.9 阈值。不可称"Q=50 已修复至100%"；正确描述："WaveGuard 除 Q=50 外≈100%，Q=50 bit-acc≈89%、成功率仅37%，仍需加强"。样本量：n=13,233 真全量。

### 3.3 LIDMark（人脸特征水印，本团队原创）

**技术原理**：将水印信号分两部分编码：(1) 人脸 dlib 关键点坐标（152维中 0:135 维），实现局部不可见的结构感知嵌入；(2) 用户 ID 比特（136:151维，编码为 {−1, +1}），实现精确身份绑定。

**关键技术细节**：
- 水印向量格式：`float32[152]`，由预计算 `.npy` 文件存储
- ID 维度的 {−1, +1} 编码与训练期间的格式严格对齐（重要：不可使用 {0, 1}）
- 三个独立训练 seed（20260603/04/05）均从相同数据集独立训练，用于 between-seed 方差估计

**LFW 多 seed 基准（n=512×3=1,536，同批 512 图重复 3 seed，95% Bootstrap CI）**：

> **重要说明**：下表为 **landmark 定位成功率**，**不是** ID 比特精度（ID 比特精度当前未测，`bit_accuracy=null`）。landmark 成功率对攻击不敏感，不代表水印鲁棒性。

| 攻击类型 | 均值 landmark 成功率 | 95% CI |
|---------|-------------------|-------|
| 无攻击 | **99.93%** | — |
| JPEG 压缩 | 99.93% | — |
| 高斯噪声 | 99.93% | — |
| 缩放 (0.5×) | 99.93% | — |

ID 比特精度评测进行中，完成后更新本表。

### 3.4 KAD-Net（注意力蒸馏水印，CVPR 2026 方向）

**技术原理**：基于 Kolmogorov–Arnold 网络和 SE (Squeeze-and-Excitation) 注意力机制的图像水印，通过 channel-wise 注意力选择最优嵌入位置，蒸馏式训练提升不可见性。

**本团队工作**：
- 在竞赛服务器（192.168.1.85）上独立训练 100 个 epoch
- 解决了 model_adapters.py 中 SE 注意力类型解析错误（training 阶段 `type_attention` 参数不一致）
- 集成到统一评测和 MEA 协议框架

**LFW 全量基准（n=13,233，checkpoint EC_50.pth，GEOM 微调版）**：

| 攻击类型 | 比特精度 | success@0.9 |
|---------|---------|-------------|
| 无攻击 | **99.98%** | 99.96% |
| JPEG Q=50 | 99.09% | 99.51% |
| JPEG Q=70 | 99.79% | 99.89% |
| JPEG Q=90 | 99.97% | 99.94% |
| 高斯噪声 | 99.93% | 99.92% |
| 缩放 | 99.97% | 99.95% |
| **crop_center_0.8** | **68.92%** | 1.14% |
| **rotate_5** | **43.73%** | 0.0% |

> JPEG/noise/resize 全部 ≥99%（真强）；**几何攻击（裁剪/旋转）实质失败**——即便已用 GEOM 微调，crop≈68.9%、rotate≈43.7%，这是已知硬限制，须诚实标注，不可隐藏。

## 四、多嵌入攻击（MEA）评测协议

### 4.1 协议定义

MEA（Multi-Embedding Attack）是本团队提出的新型鲁棒性评测协议：

1. **第一轮嵌入**：Source 模型 A 在图像中嵌入水印 $w_A$，记录解码精度 $acc_A^{(1)}$
2. **攻击嵌入**：Attacker 模型 B 在已含 $w_A$ 的图像中继续嵌入自身水印 $w_B$
3. **双路解码**：分别解码 $w_A$（检验 A 水印存活率）和 $w_B$（检验 B 嵌入成功率）

MEA 揭示的关键问题：多方内容复用场景中，后嵌入水印是否会破坏先嵌入水印的溯源有效性。

### 4.2 4×4 MEA 矩阵（n=128/cell，攻击类型：clean）

行 = Source（先嵌入），列 = Attacker（后嵌入）。括号内：A的水印存活率 | B的嵌入精度

| Source → Attacker | SepMark | WaveGuard | LIDMark | KAD-Net |
|------------------|---------|-----------|---------|---------|
| **SepMark** | 91%✅ \| 56%❌ | 92%✅ \| 100%✅ | 50%❌ \| 61%❌ | 90%✅ \| 100%✅ |
| **WaveGuard** | 100%✅ \| 95%✅ | 52%❌ \| 98%✅ | 50%❌ \| 61%❌ | 100%✅ \| 100%✅ |
| **LIDMark** | 68%⚠ \| 69%⚠ | 72%⚠ \| 100%✅ | 52%❌ \| 60%❌ | 67%⚠ \| 93%✅ |
| **KAD-Net** | 100%✅ \| 84%⚠ | 100%✅ \| 100%✅ | 50%❌ \| 61%❌ | 50%❌ \| 100%✅ |

> ✅ ≥ 90%，⚠ 70–89%，❌ < 70%

### 4.3 红队诊断发现（诚实叙事）

> **注**：MEA 当前结果以 FAIL/MARGINAL 为主（对角线均 FAIL，LIDMark 整行整列≈随机），**正确叙事是"诚实红队诊断"而非"创新有效"**。以下发现基于 n=128/格 小样本，待大样本重跑后更新。

- **核心发现**：多水印并存场景下，后嵌入水印会大幅破坏先嵌入水印的溯源能力——多数格 first_acc 降至 50–70%（随机或边缘水平），揭示了实际平台二次嵌入的安全风险。
- **LIDMark 整行整列≈随机（49–73%）**：LIDMark 作为 Source 或 Attacker 时，跨模型比特恢复极差，与 LIDMark ID 比特精度 null（landmark 成功率被误标）结论一致。
- **对角线自鲁棒性全部 FAIL**：SepMark second=56%、WaveGuard=62.8%、LIDMark≈51.8%/60.2%、KAD-Net first=50%、HiDDeN=51.3%，揭示当前自攻击场景下各模型均无法保护先嵌入水印。
- **KAD-Net + WaveGuard 相对兼容**（WaveGuard→KAD: 100%|100%，KAD→WaveGuard: 100%|100%），但对角线 KAD→KAD first=50%，说明同模型覆盖仍无效，该对的兼容性意义待进一步分析。
- **MEA 协议价值**：协议本身具有原创性，揭示了真实安全风险；但当前"创新有效"叙事需改为"诚实红队发现"，结果主要用于指导下一步增强训练方向。

## 六、应用场景

### 6.1 内容创作者保护（小红书/抖音）

创作者在发布前通过 JianYuanShield API 嵌入 ID 水印，选择最适合平台压缩策略的模型（WaveGuard 适合抖音 WebP，KAD-Net 适合高质量图集）。当内容被二次传播或经 Deepfake 替换人脸后，平台监管 API 可检测水印并溯源至原创作者，支持版权仲裁。

### 6.2 平台合规 API（监管取证）

司法机关委托平台提供取证接口：监控账号发布内容→水印解码→映射到注册创作者 ID→生成经 Ed25519 签名的证据链 JSON。证据链包含：图像 SHA-256、水印比特、解码置信度、时间戳、签名。

### 6.3 Deepfake 溯源闭环

当一张人脸图片经过 face-swap 处理后，被修改的图像仍保留原图中的水印。LIDMark 通过提取面部关键点水印可在面部替换后依然解码部分 ID 信息，实现 deepfake 来源追溯。

## 七、创新性贡献

### 7.1 技术创新

1. **MEA 协议**：将多模型顺序嵌入场景形式化为攻击协议，提供可重复的 4×4 兼容性矩阵，据调研该场景的系统性评测协议较少见
2. **LIDMark ID 维度 {−1,+1} 编码**：将用户 ID 精确编码到人脸关键点水印向量，实现比特级身份绑定
3. **统一 Adapter 架构**：解决多模型在同一 Python 进程中的命名空间隔离问题（network/ 包冲突、config 冲突）
4. **15种攻击统一库**：整合 JPEG/WebP/平台仿真/Deepfake proxy 等现实攻击为一套 API，支持各模型统一对比评测

### 7.2 工程创新

1. **三 seed 独立训练**：LIDMark 提供 between-seed 方差数据，满足统计严谨性要求
2. **Bootstrap CI 报告**：所有性能数据附带 95% Bootstrap 置信区间（5,000次重采样）
3. **证据链 Ed25519 签名**：溯源结果可用于法庭取证的数字签名方案

## 十、结论

JianYuanShield 实现了多模型协同水印溯源平台，集成四个团队原创研究模型、MEA 多重嵌入攻击评测协议、15 种攻击的统一库和 Ed25519 证据链。KAD-Net / SepMark / WaveGuard / HiDDeN 四模型均在 LFW 13,233 张全量上完成真实评测：KAD-Net（EC_50，GEOM 微调）JPEG/noise/resize 全部 ≥99%，几何攻击（crop≈68.9%/rotate≈43.7%）为已知硬限制；WaveGuard（model_state_16）除 jpeg50 外≈100%，jpeg50 bit-acc≈89%/成功率 37% 为真弱点，正在改进；SepMark（EC_115）bit-acc≈85-89%（clean 87.74%）；HiDDeN（epoch-300）clean/resize 好，JPEG 域 gap 为已知局限，作有效对照 baseline；LIDMark（512×3 张）landmark 定位成功率 99.93%，ID 比特精度评测进行中。MEA 矩阵作为诚实红队诊断，揭示多水印并存场景下后嵌入对先嵌入水印溯源的破坏规律，为主动水印系统的安全部署提供参考。
