# 鉴源盾 — 威胁模型与证据链（Threat Model）

> 定位：本文是面向"信息安全作品赛"的**正式威胁模型**，回答评委必问的"对手能不能去掉/伪造你的水印、证据链能不能被篡改"。
> 原则：**真实 benchmark 数字一律以权威真值表 `_authoritative_benchmarks.md` 为准；失效项如实标注，不隐藏、不夸大。**
> 一句话诚实结论：**普通的二次 JPEG 压缩、缩放、裁剪、旋转，已足以使本系统的部分溯源能力失效**——这不是缺陷掩盖，而是攻防边界的如实披露。

---

## 一、保护资产（Assets）

| 资产 | 说明 | 安全目标 |
|---|---|---|
| **溯源水印（traceability watermark）** | 嵌入图像的来源/ID 信息（LIDMark 16-bit id、KAD/WaveGuard 30-bit、SepMark 128-bit） | 在常见传播变换后仍可被正确解码（鲁棒性、可溯源性） |
| **存在性检测（detector）** | "这张图有没有水印"的二分类信号 | 二分类可用，但**不等于**可溯源（须与 tracer 区分） |
| **证据报告（evidence report）** | 评测 summary、协议、诊断、统计、checkpoint 清单及其签名 | 完整性自校验（被篡改可发现）+ 来源签名（出自持私钥方） |
| **演示用私钥（demo signing key）** | Ed25519 私钥，运行方现场生成、`chmod 600`、绝不入库 | 机密性（只导出公钥）；注意：演示级，无 HSM/托管 |

**明确不在保护范围内（out of scope）**：
- 不保证**抗几何攻击**（裁剪/旋转）下的溯源——真实 benchmark 显示此处失效（见 §3）。
- 不提供**法庭证明力**：时间戳为本机时钟（非 RFC3161 可信 TSA），可被持机者伪造。
- 不防御**对私钥宿主机的物理/root 级控制**：能拿到私钥即可重新签发任意 manifest。

---

## 二、对手能力分档（Adversary Tiers）

按对手对系统的了解程度与可施加的操作能力，分三档建模。每档给出对手目标、能力、对应到本系统的攻击面、以及真实 benchmark 下的预期结果。

### 档位 1 · 被动观察者（Passive Observer）
- **目标**：仅想判断/读取图像是否带水印、携带何种来源信息；不主动改图。
- **能力**：可获取传播中的图像副本、可读取公开的公钥与 manifest，可离线分析。
- **攻击面**：水印消息泄漏、检测器输出泄漏、对公开 manifest 的旁路推断。
- **预期结果**：
  - 来源信息保密性**有限**——水印本身是"可恢复信息"，被动方若持有同款解码器即可读取（这是主动取证范式的固有性质，不是 bug）。
  - 我们已做负对照（错误消息/无嵌入图≈随机），**未发现明显消息泄漏**（见 JUDGE_QA "WaveGuard 负对照"）。
  - 对证据报告：被动方无私钥，无法重签，篡改即触发 `content_mismatch`。

### 档位 2 · 主动去水印者（Active Watermark Remover）
- **目标**：让溯源失败——即图像内容仍可用，但水印无法被正确解码（success@0.9 跌破阈值）。
- **能力**：可对图像施加常见且廉价的信号处理：二次 JPEG 压缩、缩放、加噪、**裁剪、旋转**；可二次嵌入其他水印（多水印共存，MEA 场景）。
- **攻击面**：解码器对几何/压缩失真的脆弱性；多水印覆盖（后嵌入摧毁先嵌入）。
- **预期结果（真实 benchmark，见 §3）**：
  - **几何攻击（裁剪/旋转）即可使 KAD-Net 溯源实质失效**（crop 68.9%/rotate 43.7%，success@0.9 仅 1.14%/0%）。
  - **二次 JPEG Q=50 即可使 WaveGuard / HiDDeN 溯源失效或大幅下降**（WaveGuard jpeg50 success 仅 37.3%；HiDDeN jpeg50 success 0%）。
  - **多水印二次嵌入（MEA）会摧毁先嵌入水印的可溯源性**（first_acc≈0.5≈随机），这是本系统主动披露的红队发现。

### 档位 3 · 自适应攻击者（Adaptive / White-box Attacker）
- **目标**：在已知本系统模型与防御细节的前提下，最小化可感知失真地去除或伪造水印。
- **能力**：白盒掌握编码器/解码器结构与权重（或可查询）、可做对抗扰动优化、可用扩散模型做"净化"（diffusion purification）重生成图像、可针对解码器做梯度攻击。
- **攻击面**：对抗样本（针对解码器的 evasion）、扩散净化（重采样掉高频水印）、伪造（在不持私钥时无法重签证据，但可对图像层伪造来源水印）。
- **预期结果**：
  - 当前模型**未针对自适应对手做对抗训练**，预期对扩散净化/对抗扰动**鲁棒性弱**（待 §4 实验量化）。
  - 证据链层面：自适应对手**无法伪造签名**（无私钥），但若取得私钥宿主机控制权则可重签任意 manifest——这是演示级密钥管理的边界。

## 三、各模型在真实 benchmark 下的失效边界

> 数据来源：`_authoritative_benchmarks.md`（远端 `system/reports/*/summary.json` 实测，权威）。
> 标注规则：bit-acc 与 success@0.9 同列；**FAIL = success@0.9 实质失效**（≈随机或远低于阈值）。

### KAD-Net（EC_50.pth，GEOM 微调，n=13,233 全量）
| 攻击 | bit-acc | success@0.9 | 判定 |
|---|---|---|---|
| clean / jpeg / noise / resize | 99.09%–99.98% | ≥99% | 强 |
| **crop_center_0.8** | **68.92%** | **1.14%** | **FAIL（几何）** |
| **rotate_5** | **43.73%** | **0.0%** | **FAIL（几何）** |
- **失效边界**：即便已做 GEOM 几何微调，**裁剪与旋转仍使溯源实质失效**。社交平台转发普遍伴随裁剪/旋转，故 KAD-Net 在真实传播链上的几何鲁棒性是已知硬限制。

### WaveGuard（model_state_16.pth，n=13,233 全量）
| 攻击 | bit-acc | success@0.9 | 判定 |
|---|---|---|---|
| clean / jpeg70 / jpeg90 / noise / resize | 99.68%–100% | ≥99% | 强 |
| **jpeg50** | **88.97%** | **37.3%** | **FAIL（强压缩）** |
- **失效边界**：**二次 JPEG Q=50（强压缩）即可使 WaveGuard 溯源失效**——bit-acc 看似 89%，但只有 37% 的图达到 success@0.9 阈值。主流平台 Q=75–85 仍≈100%，但低质量二压/多次转存场景失效。**"jpeg Q=50 已修复至 100%"是不成立的说法。**

### HiDDeN（epoch-300，n=13,233 全量，对照 baseline）
| 攻击 | bit-acc | success@0.9 | 判定 |
|---|---|---|---|
| clean / resize | 98.07%–99.05% | ≥97% | 好 |
| noise | 93.31% | 68.30% | 中等 |
| **jpeg50 / jpeg70 / jpeg90** | 57%–67% | **≈0%** | **FAIL（JPEG 全系列）** |
- **失效边界**：**任意 JPEG 压缩即可使 HiDDeN 溯源完全失效**（域 gap）。作为有效对照 baseline，它如实揭示了"公开 watermark checkpoint 不能假定跨域可迁移"。

### SepMark（EC_115.pth，pre-trained 第三方 baseline，n=13,233 全量）
| 攻击 | bit-acc | success@0.9 | 判定 |
|---|---|---|---|
| clean / jpeg / noise / resize | 84.65%–89.23% | 59%–72% | 中等（128-bit 长消息门槛严） |
- **失效边界**：128-bit 长消息下 success@0.9 仅 59–72%，**即使在 clean 条件下也有约 1/3 的图无法达到溯源阈值**。"decoder_RF 91.2%"偏高，以 ≈88% 为准。

### LIDMark（3-seed ep100，n=512×3）
- landmark 定位成功率 ≈**99.93%**（landmark_aed≈0.01px）——**真实强项，但这是关键点定位精度，不是水印比特精度**。
- **16-bit ID 水印的比特准确率尚未单独测量**（`mean_bit_accuracy=0.0 / per-seed=null`，real gap）。MEA 中 LIDMark 16-bit id 跨模型≈50–73%，提示单模型 id-bit 鲁棒性也需如实补测。
- **失效边界（暂定）**：在 16-bit id 比特级证据补齐前，**不可声称 LIDMark 具备攻击下的可溯源比特精度**。

### MEA 多水印共存矩阵（128 图/格）
- 对角线（自鲁棒性）及多数跨模型格 first_acc≈0.5（随机）——**后嵌入水印会摧毁先嵌入水印的可溯源性**。
- 这是**诚实的红队诊断发现**（"多水印共存下溯源失败"），不是"创新很强"的卖点；`first_acc` 是"先嵌水印被二次嵌入覆盖后的残留可解率"，≈0.5 即被覆盖，是预期内结果。

### 失效边界汇总（诚实结论）
- **普通二次 JPEG 压缩（Q≤50）→ WaveGuard / HiDDeN 溯源失效。**
- **裁剪 / 旋转 → KAD-Net 溯源实质失效。**
- **多水印二次嵌入 → 先嵌入水印溯源被摧毁（MEA）。**
- **缩放 / 温和 JPEG（Q≥70）/ 高斯噪声 → KAD-Net / WaveGuard 鲁棒（≥99%）。**
- 即"系统在**温和传播变换**下可溯源，在**强压缩/几何/多水印**下部分失效"——这是当前真实的攻防边界。

## 四、去水印 evasion 实验计划

> 目的：把 §2 档位 2/3 对手的能力量化成可复现的失效曲线，作为"我们知道边界在哪"的诚实证据，而非掩盖。
> 统一协议：复用 `configs/evaluation_protocol.v1.json`，success@0.9 阈值，bit-acc 与 success 双指标，CI 与 n 标注；样本用与训练域不重叠的留出集。

### 实验 E1 · 几何攻击扫描（档位 2）
- **攻击**：crop_center ∈ {0.9, 0.8, 0.7, 0.6}；rotate ∈ {±2°, ±5°, ±10°}；组合 crop+rotate。
- **对象**：KAD-Net（重点）、WaveGuard、SepMark。
- **指标**：每攻击点 bit-acc / success@0.9 / CI / n；画"失真强度 → 溯源成功率"曲线。
- **预期**：复现 KAD-Net crop 0.8≈68.9%、rotate 5°≈43.7%，定位几何鲁棒性的失效拐点。

### 实验 E2 · 扩散净化（diffusion purification，档位 3）
- **攻击**：用预训练扩散模型对水印图做"加噪→去噪"重生成（如 DDPM 前向加噪到 t 步再反向采样），扫描噪声步数 t。
- **对象**：全部模型。
- **指标**：净化强度（t / PSNR 损失）→ 溯源 success@0.9；同时报告净化后图像感知质量（LPIPS/SSIM）以体现"对手代价"。
- **预期**：高频嵌入（WaveGuard DTCWT 高频子带）在净化下预期快速失效；量化"对手付出多少可感知失真才能去水印"。

### 实验 E3 · 对抗扰动（adversarial evasion，档位 3，白盒）
- **攻击**：对解码器做 PGD/FGSM 类对抗优化，在 L∞ 扰动预算 ε 内最小化正确解码概率。
- **对象**：KAD-Net / WaveGuard / SepMark（需解码器可微）。
- **指标**：ε（扰动预算）→ success@0.9 衰减曲线；报告 ε 对应的可感知失真。
- **预期**：未做对抗训练的解码器在小 ε 下即被攻破，量化白盒脆弱性；作为后续"对抗训练加固"的 baseline。

### 实验 E4 · 多水印覆盖加压（档位 2，MEA 扩展）
- **攻击**：在 §3 MEA 基础上，对二次嵌入后图像再叠加 JPEG/几何攻击，模拟"覆盖+压缩"组合链。
- **对象**：MEA 5×5 全矩阵。
- **指标**：first_acc / second_acc / CI / n，每格标 msg_len 与 decoder，相对随机基线 0.5 归一化。
- **预期**：进一步坐实"多水印共存下溯源不可靠"的红队结论，并区分协议创新与结果有效。

### 实验产出与诚实披露要求
- 所有失效项（success@0.9 跌破阈值）**如实进主表/答辩**，标 FAIL，附 n 与 CI。
- 对手代价（达到去水印所需的可感知失真）一并报告，避免只报"被攻破"而不报"代价多大"。
- evasion 结果回填后，`demo.py` 的 `security_conclusion` 应改为**基于真实 bit/tracer 阈值**判定，而非按"有无 attack"二值贴标签。

## 五、证据链威胁模型（与 `signing.py` 对齐）

> 诚实定位：实现为**完整性自校验 + 来源数字签名（演示密钥，Ed25519）+ 追加式弱链（prev_hash）**，**不是**"司法级防篡改证据链"。

| 威胁 | 当前防御 | 边界 / 残余风险（诚实披露） |
|---|---|---|
| 篡改已覆盖的证据文件 | manifest 记录每文件 SHA-256，校验触发 `content_mismatch` | 仅覆盖 `default_evidence_files()` 列表内文件；列表外文件不在保护内 |
| 替换/伪造整份 manifest | Ed25519 签名 + `prev_hash` 追加式弱链（新 manifest 携上一份哈希、`record_seq` 单调递增） | **弱链非 Merkle、无外部锚定**；持私钥方可重签整条链 |
| 伪造时间 | manifest 记 `generated_at` + `time_source='local_clock'` | **本机时钟可被持机者伪造，非 RFC3161 可信 TSA**，无法庭证明力 |
| 冒充签发方 | 私钥现场生成、`chmod 600`、绝不入库，仅导出公钥 | 私钥与验签器同机、无 HSM/密钥托管；取得宿主机 root 即可重签 |

**做实路线（加分项，时间允许）**：接入 RFC3161 可信时间戳机构；私钥离线/HSM 生成仅导出公钥；manifest 链升级为 Merkle 树 + 外部锚定（如公开账本/时间戳服务）。在做实前，对外措辞一律保持"演示级完整性自校验 + 来源签名"的诚实口径。
