# 创新点（鉴源盾 · 主动水印 Deepfake 溯源系统）

> 全部数值为真实测得（脚本 + `system/reports/*/summary.json`），并经**对照/held-out/泛化检验**把关。
> 详见 `docs/LARGE_SCALE_EXPERIMENTS.md`（大规模实验报告，诚实版）。

## 1. 多模型主动水印算法族，按攻击面"用对模型"而非单模型全能
团队原创 LIDMark / KAD-Net / WaveGuard / MEA，统一产品化为鉴源盾，覆盖内容保护→传播攻击→溯源/篡改定位→证据报告完整链路。**关键设计判断（有实验支撑）**：不同攻击需不同嵌入域——
- **信号级攻击（JPEG/缩放/平台转码/uint8 往返）**：KAD-Net 跨数据集 clean/JPEG/平台 ≥99%（真/假脸一致），旗舰鲁棒；
- **几何攻击（裁剪/旋转）**：**必须由几何不变的嵌入架构提供**——HiDDeN（CNN 嵌入）crop 0.7–0.9、rotate ±3–±10° 全 **94–96%** 且跨参数泛化（已验证）；而 DTCWT 子带水印（KAD/WaveGuard）经**四种**改造（固定/范围微调、解码端模板重同步、可学习 STN）仍不可学，证实几何不变性**无法在解码端事后修补**。→ 这正是多模型系统的价值：用对模型。

## 2. 对抗式"AI 再生成"硬化，并对**未见再生成器**泛化（前沿贡献）
生成式再生成（图过一遍 AE/扩散重生成）是现代去水印的最强攻击，基线下水印再生成后成功率≈0。本系统将**自训练 AE 再生成**纳入 STE 对抗训练（前向真实再生成、反向恒等），并以**AE 集成训练 + 完全留出的 held-out AE 验收**防止过拟合到单一再生成器：
- **未见再生成器（held-out AE）上存活率 0.3%→68%、bit-acc 0.60→0.91**（真泛化，非记忆训练 AE），clean/JPEG 保持 ~100%。
- 诚实给出 **imperceptibility↔robustness 内禀权衡**（强溯源工作点 PSNR≈14，半可见）与可选工作点，而非伪称"零代价解决"。
据调研，主动水印"对未见生成式再生成器泛化"的系统性验证较少见。

## 3. 分块独立水印篡改定位（攻克全局水印无法定位的难题）
全局消息水印拼接篡改后或整体存活或整体降级，**无空间区分度**（实测遮挡敏感度 AUC≈0.5；LIDMark landmark 位移法表面 0.94 经**均匀权重对照**证伪为中心先验假象）。改用**每空间块嵌入独立水印**：被篡改块自身水印被破坏→逐块比特准确率定位篡改区——**grid4 AUC 0.948**，三档对照证实为真定位（clean 各块 0.905 均匀、篡改区内块 0.55 « 区外块 0.87，与位置无关）。

## 4. 方法论严谨性：每个"解决"都有对照/泛化护栏（本身是贡献）
项目刻意为每项结论内置护栏，并据此**多次拦下会误判为"已解决"的过度宣称**：
- 篡改定位 landmark 位移法 AUC 0.94 → 均匀权重对照揭穿为中心先验（真实增益≈0）；
- 几何固定参数微调 crop_0.8→0.99 → held-out 参数（crop_0.7/0.9、rotate_3/10/-5）≈0.5，揭穿为参数记忆；
- 再生成硬化 → held-out AE 验证排除"记忆单一再生成器"。
"结构保持的攻击（信号级）可学且泛化，结构改变的攻击（几何）不可学"是干净可复现的科学结论。

## 5. MEA 多重嵌入攻击红队协议
以多水印并存场景的系统评测，揭示后嵌入对先嵌入水印的破坏规律（`first_acc≈0.5` 为预期红队发现，附口径对照表）；多水印共存的系统性评测协议在文献中较少见。

## 6. 大规模真实评测 + 关键测量更正
- KAD-Net/SepMark/WaveGuard/HiDDeN 四模型均在 **13,233 张 LFW 全量**完成真实评测；另在 **19 万张真/假人脸**（`Hemg/deepfake-and-real-images`）上验证跨数据集泛化与 **AIGC 合成脸可水印性**（KAD/SepMark/HiDDeN clean≥96%，可对 AI 生成内容主动溯源）。
- **LIDMark 16-bit ID 比特更正**：旧"≈随机 62%"是 MEA 模式 landmark 置零的 OOD 测量假象；完整配置（face_alignment 真实 landmark）正测 **clean 99.8%/jpeg50 99.9%≈100%**——id 溯源能力实为强项。
- **WaveGuard 信号鲁棒修复**：自行重建缺失的 STE 噪声层联合微调，使其在真实 uint8 往返 + JPEG 下 ~72%→~100%，并泛化到 held-out 信号攻击（webp/bright/contrast）。
- 主动水印 vs 被动检测：ResNet18 检测器 val AUC 0.99，但主动水印提供**确定性**溯源——互补叙事。

## 7. 可验签证据链 + 双模式前端
取证任务记录输入/输出 SHA-256，结合 Ed25519 签名生成可独立验签的证据包；前端同时提供交互式单样本演示与全量 benchmark 证据，避免静态展示。
