# 寻源路 · 鉴源盾微信小程序端

> AIGC 图像隐水印主动溯源与取证验证小程序。  
> 本项目依托 **微信开发者工具** 运行，用于演示“图片上传—主动水印验证—攻击模拟—溯源取证—证据审计”的移动端闭环能力。

## 1. 项目简介

“寻源路”是“鉴源盾”项目的小程序客户端，面向移动端轻量化取证场景设计。小程序通过调用后端 FastAPI 服务，对用户上传的图片进行隐水印检测、攻击后恢复、合规判定和证据链展示，帮助用户快速判断图片内容是否存在可验证来源，并展示对应的取证指标。

小程序主要服务于以下场景：

- **创作者保护**：创作者上传图片，验证图片是否能够完成主动水印保护与来源确认。
- **深度伪造溯源**：对疑似被压缩、扰动或伪造处理后的图片进行水印恢复与取证分析。
- **平台合规检测**：批量检测图片是否包含合规隐式标识，辅助内容平台进行初步审核。
- **证据链展示**：展示任务 ID、哈希摘要、合规结论、Ed25519 签名审计等取证信息。
- **多模型横评**：对 SepMark、WaveGuard 等模型进行同图对比，展示不同水印方案在攻击扰动后的表现。

## 2. 功能概览

| 模块 | 功能说明 |
|---|---|
| 取证检测 | 从相册或相机选择图片，选择水印模型与攻击方式，调用后端完成推理检测。 |
| 结果展示 | 展示原图、含水印图、攻击后图、热力图、Bit Accuracy、PSNR、合规结论等结果。 |
| 证据审计 | 调用后端证据审计接口，展示 Ed25519 验签状态、公钥指纹、审计阻断项等。 |
| 批量合规 | 支持多张图片批量检测，统计合规、降级、无水印等结果。 |
| 检测历史 | 本地保存历史检测记录，便于回看最近检测结果。 |
| MEA 横评 | 对同一张图片使用不同水印模型进行横向对比分析。 |
| 分享海报 | 可生成检测结果摘要海报，便于移动端展示和分享。 |

## 4. 运行环境

运行本小程序需要准备：

1. **微信开发者工具**：用于导入、编译、模拟器预览和真机预览。
2. **小程序 AppID**：可以使用项目配置中的 AppID，也可以替换为自己的测试号或正式 AppID。
3. **后端服务**：小程序需要访问鉴源盾后端 API，默认端口为 `8026`。
4. **网络连通性**：开发工具或真机需要能够访问 `utils/config.js` 中配置的后端地址。

本项目为原生微信小程序项目，当前没有引入 npm 依赖，因此一般不需要执行 `npm install` 或“构建 npm”。

## 5. 后端地址配置

后端 API 地址位于：

```text
utils/config.js
```

默认配置如下：

```js
const API_BASE = 'http://216.167.91.193:8026';

module.exports = { API_BASE };
```

如果需要更换后端地址，只需要修改 `API_BASE`：

```js
// 示例：本地后端
const API_BASE = 'http://127.0.0.1:8026';

// 示例：局域网后端，真机调试时常用
const API_BASE = 'http://192.168.x.x:8026';

// 示例：正式部署或真机稳定演示，建议使用 HTTPS 域名
const API_BASE = 'https://your-domain.com';
```

注意：

- 开发阶段可在微信开发者工具中关闭合法域名校验，用于模拟器或调试预览。
- 真机预览时，手机必须能访问该后端地址。
- 正式发布时，后端应使用 HTTPS 域名，并在微信公众平台配置为合法服务器域名。
- 若后端地址不可达，小程序首页右上角状态会显示“离线”，上传检测和证据审计功能会失败。

## 6. 使用微信开发者工具运行

### 6.1 解压项目

将压缩包解压到本地，例如：

```text
miniprogram-v9/
```

请确保打开的是包含 `project.config.json` 的目录，而不是它的上一级目录。

### 6.2 导入项目

打开微信开发者工具，选择：

```text
导入项目 → 选择 miniprogram-v9 目录 → 填写或确认 AppID → 导入
```

导入时建议选择：

- 项目类型：小程序
- 后端服务：不使用云服务
- 编译模式：普通编译

### 6.3 编译运行

导入成功后，点击微信开发者工具顶部的：

```text
编译
```

正常情况下，模拟器会进入“寻源路”首页。首次进入时会出现启动动画和用户信息设置界面，设置头像昵称后即可进入主功能页面。

### 6.4 检查后端连接

进入首页后，观察右上角状态：

- `在线`：说明 `/api/health` 接口可访问，可以继续进行图片检测。
- `离线`：说明小程序无法访问后端，需要检查 `API_BASE`、后端服务状态、端口、防火墙和网络环境。

## 7. 主要操作流程

### 7.1 单图取证检测

1. 进入首页“取证”模块。
2. 点击图片区域，从相册选择图片或拍照。
3. 选择水印模型，例如 `SepMark` 或 `WaveGuard`。
4. 选择攻击方式，例如 `JPEG50`、`JPEG70`、`缩放`、`噪声`、`模糊` 或 `无攻击`。
5. 点击开始检测。
6. 查看检测结果，包括：
   - 原图
   - 含水印图
   - 攻击后图
   - 热力图
   - Bit Accuracy
   - PSNR
   - 合规结论
   - 任务 ID
   - 证据 JSON

### 7.2 使用内置样本

如果暂时没有测试图片，可以点击“用内置样本”。小程序会从后端样本接口下载样例图片，并进入检测流程。

### 7.3 证据审计

切换到“证据”页面，可以查看：

- Ed25519 签名验证状态
- 公钥指纹
- 审计阻断项数量
- 证据链 findings
- 系统是否 ready for demo
- 系统是否 ready for claims

该页面主要用于展示系统的可信取证和密码学存证能力。

### 7.4 批量合规检测

在“证据”页面中可以进行平台合规批量检测：

1. 点击选择多张图片。
2. 选择检测模型。
3. 点击开始批量检测。
4. 查看合规、降级、无标识等统计结果。

### 7.5 MEA 多模型横评

进入“MEA 多模型横评”页面后：

1. 选择一张图片。
2. 选择攻击方式。
3. 系统会分别调用多个模型进行检测。
4. 对比不同模型的 Bit Accuracy、PSNR、合规结论和热力图。

## 8. 后端接口依赖

小程序主要依赖以下接口：

| 接口 | 方法 | 用途 |
|---|---|---|
| `/api/health` | GET | 检查后端是否在线。 |
| `/api/samples` | GET | 获取内置样本列表。 |
| `/api/samples/{id}/image` | GET | 下载内置样本图片。 |
| `/api/infer/single` | POST multipart | 单图水印嵌入、攻击模拟、取证恢复与合规判定。 |
| `/api/evidence/audit` | GET | 获取证据审计与签名状态。 |

其中 `/api/infer/single` 上传参数包括：

| 参数 | 说明 |
|---|---|
| `file` | 用户选择的图片文件。 |
| `model` | 水印模型名称，例如 `SepMark`、`WaveGuard`。 |
| `attack` | 攻击方式，例如 `clean`、`jpeg50`、`jpeg70`、`resize`、`noise`、`blur`。 |
| `return_b64` | 是否返回 base64 图片结果，页面展示结果图时应设置为 `true`。 |

## 9. 真机调试说明

真机调试前请重点检查三点：

1. 手机和后端服务器网络互通。  
   如果后端部署在本机，手机通常不能访问 `127.0.0.1`，需要改成电脑的局域网 IP，或使用公网/内网穿透地址。

2. 后端地址配置正确。  
   修改 `utils/config.js` 中的 `API_BASE` 后，需要重新编译小程序。

3. 合法域名问题。  
   开发调试可关闭合法域名校验；正式发布必须使用 HTTPS，并在微信公众平台配置 request/uploadFile 合法域名。

## 10. 常见问题

### Q1：打开后显示“离线”怎么办？

说明 `/api/health` 访问失败。请检查：

- 后端服务是否已经启动。
- `utils/config.js` 中的 `API_BASE` 是否正确。
- 端口 `8026` 是否开放。
- 手机或开发工具是否能访问该地址。
- 是否被防火墙、安全组或服务器策略拦截。

### Q2：上传图片后提示网络错误或上传失败怎么办？

请检查：

- `/api/infer/single` 接口是否可用。
- 后端是否支持 multipart 文件上传。
- 图片文件是否过大。
- 真机预览时后端域名是否可访问。
- 正式版是否已经配置 uploadFile 合法域名。

### Q3：结果中没有图片怎么办？

请确认上传时 `return_b64` 参数为 `true`，并确认后端返回中包含 `artifacts_b64` 字段。

### Q4：可以不连接后端运行吗？

可以打开小程序界面，但取证检测、样本下载、证据审计等核心功能都依赖后端 API。完整演示必须启动后端服务。

### Q5：需要构建 npm 吗？

当前项目没有 npm 依赖，一般不需要构建 npm。如果后续加入第三方组件库，再根据组件库要求执行 npm 构建。

## 13. 项目定位总结

本小程序不是单纯的界面展示，而是鉴源盾系统面向移动端的轻量化取证入口。它将后端的隐水印模型、攻击模拟、溯源恢复、合规判定和证据审计能力封装为普通用户可以直接操作的移动端流程，体现了作品从算法研究到真实应用场景落地的工程化能力。
