# LIDMark 五种子攻击评测输入清单

本目录冻结 2026-08-08 启动的五星种候选权重评测输入。每份清单在推理前生成，
绑定模型选择报告、检查点、训练配置、入选轮次、文件大小和训练随机种子。

评测器只在下列条件全部满足时加载候选权重：

- 清单 schema 为 `jys.lidmark.evaluation-inputs.v1`；
- 三个 SHA-256 字段均为完整十六进制摘要；
- 选择报告的入选 Epoch 与清单一致；
- 检查点摘要和字节数同时一致；
- 训练配置摘要和配置内随机种子同时一致；
- 选择报告确认全部检查点完成完整性审计。

五份清单对应 GPU 1–5 上相互独立的固定协议任务。每个任务评测 1,324 张身份隔离
LFW 测试图、15 类攻击和 19,860 行结果；完整矩阵计划产生 99,300 行原始证据。
候选结果写入独立报告目录，不覆盖既有 Epoch-20 release 基线。
